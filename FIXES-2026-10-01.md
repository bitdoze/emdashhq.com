# Review fixes, 1 October 2026

Implemented the site-level fixes from `REVIEW-2026-10-01.md`. The existing `prefetchAll: true` and `defaultStrategy: "hover"` configuration is unchanged. Deployed to `https://emdashhq.com` at the user's request. No production CMS content or database schema was edited. Final Worker version: `aad7ff53-dd8f-45ca-86ce-0b0591267af5` (1 October 2026).

## Changes

- Fetch page content and shared menus/settings concurrently. Reuse these results within the request, and deduplicate equivalent plugin fragment contexts so head/body rendering shares the settings read.
- Register every displayed collection's cache hints, including empty results and every cursor page. Move featured/resource filters and service ordering into CMS queries. Bounded blocks request their required limit; `0 = all` follows cursors in batches of 100. Invalid video URLs no longer consume the playable-video limit.
- Finish collection reads before document streaming. Failed queries return a generic 503 with `Cache-Control: no-store`, `Retry-After`, and route caching disabled, rather than a successful empty list or false 404. Server logs retain the error. `X-Site-Data-Ms` measures page, chrome, and list loading; CMS `Server-Timing` still measures initialization and rendering.
- Override the collection sitemap route to correct page URLs and map `home` to `/`. The installed CMS handler still provides noindex exclusions, modification dates, SEO images, and other collection sitemaps. This works with the existing database. Set the seed's pages URL pattern for new installations.
- Redirect unslashed content URLs to their slashed equivalents, preserving query parameters. Keep the home alias redirect. Share normalized current-menu matching with Hero, including absolute same-origin links.
- Emit large CSS as reusable assets. Make hero text/actions visible immediately and restrict decorative drawing to the homepage. Remove fixed telemetry claims.
- Restore flat surface/shadow tokens and solid control colors. Protect public theme tokens from bundled admin `:root` declarations. White labels on filled controls have 8.72:1 normal and 6.70:1 hover contrast. Brighter dark link ink has 8.26:1 contrast on the card surface. Refresh design documentation and its sidecar.
- Keep mobile navigation visible without JavaScript. Add Escape closing and focus return after enhancement. Transfer focus to an activated video iframe and preserve modified clicks.
- Tag public responses for Site Scripts and await a purge after a successful authenticated settings save. Failed/unauthorized saves do not purge; purge failures return a private, noncached API error indicating that settings were saved. Production checks the native platform result because the installed Astro provider discards it. HTTPS public responses add HSTS without extending it to subdomains.

## Deployment and remaining measurements

Cloudflare Workers Cache partitions responses by deployment version by default. This project does not enable `cross_version_cache`, so the deployed version starts with a fresh HTML/sitemap cache. If cross-version caching is introduced later, purge old rendered responses through the Worker cache API/provider; a zone CDN purge does not clear Workers Cache. Future rendered responses carry the new dependency/Site Scripts tags.

Production cold initialization and D1 latency remain material after deployment. Live miss samples ranged from 672.4 to 2,420.7 ms; repeat hits ranged from 62.1 to 98.0 ms. These are single-location samples, not a controlled improvement percentage. The changes remove visible entrance delays and reduce document CSS repetition. Further origin optimization remains open. Compare Cloudflare HIT/MISS status, CMS `Server-Timing`, and `X-Site-Data-Ms`; local development disables HTML caching and has different database latency.

The sitemap wrapper imports the installed EmDash internal route export. Recheck this import and the URL mapping when upgrading EmDash. The seed update does not migrate the existing database's collection URL pattern; the runtime sitemap override handles this site's current routing independently.

“All” listings now include every matching entry, which can still produce a large document for a large collection. Their cursor traversal preserves the existing editor setting; numbered archive UI can be added separately if needed.

No restrictive public CSP was added: it requires an explicit policy for the site's analytics, media, inline code, and intentional administrator HTML. Authenticated production editing and a real settings-change edge purge were not exercised. Deployment created a fresh version cache under the platform default. Live checks confirmed seven sitemap/canonical pages, new response markers/HSTS, 301 redirects, a genuine 404, and 401/private/no-store for plugin settings. Chromium observed the existing hover prefetch and an approximately 93.4 ms menu navigation, no mobile overflow, working Escape closing, and zero runtime exceptions.
